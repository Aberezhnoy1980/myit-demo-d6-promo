Данные и состояние отделены от интерфейса и хранилища. Тесты: `npm test`, Node 22.23.4, 5/5. Новых пакетов, Git, внешних интеграций и публикации нет.

## Состояния

```text
Вход 0/8 ──начать──> вопрос N ──неверно──> подсказка ──повтор──> вопрос N
                         │
                         └──верно──> модуль + ответ ──> следующий вопрос / 8/8
Вход с сохранением ──продолжить──> первый нерешённый вопрос / итог
Любое состояние ──начать заново──> подтверждение ──да──> 0/8
                                              └──отмена──> прежнее состояние
```

Ключ `myit.d6.light.v1`: JSON версии 1 с правильными ответами по стабильным ID. Счётчик и следующий шаг вычисляются. Срок хранения не ограничен приложением: данные остаются до сброса пользователем или очистки хранилища браузером. Неизвестная версия и повреждённые данные не восстанавливаются. При ошибке хранилища игра продолжается в памяти с предупреждением. Передачи наружу нет. Подделка правильных ответов в локальном хранилище технически возможна; это не защита акции.

Две вкладки: событие storage заменяет состояние актуальным сохранением, включая сброс. Одновременные записи могут разрешиться по принципу последней записи, с потерей более раннего изменения; синхронизация и гонка в браузере не проверены. Back/Forward не меняет шаги: отдельные записи истории для них не создаются.
