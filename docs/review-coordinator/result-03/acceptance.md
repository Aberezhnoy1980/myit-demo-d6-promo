## Подача и комплект

На входе теперь есть пример будущей карточки, явный путь из трёх шагов и объяснение результата.
Разные сценарии/наборы дают действительно разные экспортируемые карточки; это не переименование одинакового 8/8.
Сохраняется честная граница: концептуальная композиция вымышленной коллекции,
не проект электрики/расчёт освещения/подбор имеющегося товара. Призов/покупок/сбора контактов нет.
Просмотрены независимые start-1440, rest-390 и offline work/rest; новые снимки/скачанные файлы рядом.

Семь публичных исходных файлов: index.html, style.css, app.js, card.js, data.js, state.js, storage.js.
Их файловый объём 38 065 байт, собственный JS 27 541 байт / gzip 9 113 байт.
Это оценка по файлам, не network waterfall; отдельная готовая папка публичного релиза здесь не создавалась.
README и описание кейса обновлены автором; docs/evidence/tests в будущую публичную поставку не включать автоматически.

## Ограничения

Не проверены настоящий browser zoom 200%, VoiceOver, физические устройства, другие движки,
полный контраст/WCAG, одновременная гонка записей, Back/Forward и отказ CSS/JS.
Обычная синхронизация двух вкладок отдельно на новом v3-срезе этим прогоном не проверялась;
прежний v2-прогон не выдаётся за новый результат. Документированная модель last-writer-wins сохраняется.
Подделываемое локальное состояние не является защитой призовой акции; такой акции в кейсе нет.

Установок/Git/публикации/внешних API не было. Основной сервер 4336 остановлен после проверки
(Keyboard interrupt/exit 0); временный 4338 остановлен в тесте.
