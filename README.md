# СВЕТ / СБОРКА — D6

Локальный демонстрационный прототип вымышленной коллекции света. После восьми сцен посетитель выбирает задачу и 2–3 модуля, получает личную карточку и может сохранить её как самостоятельный SVG. Это образ композиции, а не расчёт освещения, проект электрики или подбор реального товара.

Запуск из этой папки: `python3 -m http.server 8000 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8000/`. Остановка — Ctrl+C. Для unit-тестов: `npm test` (проверено Node 22.23.4, установки не требуются). Приложение использует относительные пути. Backend, настройки контактов, внешние API и сборка не требуются; публикация отдельно не согласована.

Повторный срез задания 16 ожидает независимого ревью. Актуальные результаты — в конце docs/acceptance.md и docs/report.md. `tests/browser-v3.mjs` использует уже установленный на этой машине Chrome и имеющийся Playwright по абсолютному пути; это не зависимость приложения. Старый browser-review.mjs относится к версии 2 и сохранён как историческое свидетельство.
