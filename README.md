# СВЕТ / СБОРКА — промоакция «Долгие вечера» (демо)

Демо-промолендинг вымышленного салона света. Темнеет рано — посетитель обходит пять комнат своего дома, видит, что мешает в каждой, подбирает светильники из коллекции и сразу видит комнату с новым светом. Скидка растёт с числом освещённых комнат: 2 — −5%, 3 — −10%, все 5 — −15% и монтаж в подарок. В конце — комплект с итогом и промокодом, демо-оформление и честный экран «здесь заказ ушёл бы в салон». Салон, цены и акция вымышлены; ничего не продаётся, не оплачивается и не отправляется, контакты не собираются.

## Запуск

Из корня проекта: `python3 -m http.server 4391 --bind 127.0.0.1`, открыть `http://127.0.0.1:4391/`. Самостоятельный комплект страницы — `public/` (свой SHA256SUMS): `python3 -m http.server 4392 --bind 127.0.0.1 --directory public`. Backend, внешние API, зависимости и сборка не нужны; пути относительные. Публикация не выполнялась и требует отдельного решения.

## Устройство

| Файл | Назначение |
|---|---|
| index.html, style.css | Каркас, статичная версия без JavaScript, стили |
| app.js | Экраны и hash-маршруты: `#/`, `#/dom`, `#/komnata/<id>`, `#/komplekt`, `#/oformlenie`, `#/gotovo` |
| data.js | Комнаты, изделия, цены, уровни скидки, условия оформления |
| state.js, storage.js, legacy.js | Модель v5, ключ `myit.d6.light.v1`, миграция сохранений v1–v4 |
| house.js, rooms.js, art.js | Собственные SVG: разрез дома, пять сцен комнат, восемь изделий |
| card.js | Текст подборки и автономный SVG (из него же PNG-открытка) |
